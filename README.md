# Auction Ease

Auction Ease is an IPL player auction recommendation tool. It filters players by role and bowling style, then ranks eligible players using batting, bowling, or balanced performance priorities. The Streamlit app also provides player profiles, comparisons, and a shortlist that can be downloaded as a CSV.

## Features

- Filter players by role: batter, wicketkeeper, bowler, all-rounder, or any role.
- Filter bowlers and all-rounders by fast or spin bowling style.
- Rank players by batting, bowling, or balanced performance.
- Browse player statistics, compare players, and export a shortlist.
- Use trained ML models when available, with a weighted-statistics ranking fallback.

## Requirements

- Python 3.10 or later
- Packages listed in `requirements.txt`

## Run the app

From the project root, create and activate a virtual environment, then install the dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Start the Streamlit app:

```powershell
streamlit run App.py
```

The app loads `data/processed/player_features.csv`. This dataset and the trained model artifacts are included in the repository.

## Command-line recommender

The interactive command-line workflow asks for a player role, bowling style where applicable, and performance priority:

```powershell
python main.py
```

It prints up to 15 recommended players from `data/processed/player_features.csv`.

- `data/processed/` — player datasets, features, embeddings, and model evaluation outputs.
- `models/` — trained ranking and temporal encoder models.

## Rebuild data and models

The scripts expect their source datasets in `data/processed/`. Run these from the project root when the required source files are available:

```powershell
python lstm_model.py
python combine_player_features.py
python train_model.py
```

`lstm_model.py` uses `player_history.csv`; `combine_player_features.py` uses `player_profiles.csv` and the embeddings generated by the first script; `train_model.py` uses `player_match_final_roles.csv`. The recommender can use the trained performance model at `models/auction_ease_performance_models.joblib`; if it is unavailable or cannot be used, ranking falls back to weighted statistics.

## Notes

The performance model is trained on historical season-level features. At recommendation time, some of its inputs are estimated from profile and recent-form summaries, so treat its predictions as guidance rather than a guarantee of future performance.
